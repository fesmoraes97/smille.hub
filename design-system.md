# Design System — Smille Hub

## 1. Tokens de Cor

| Token | Valor |
|---|---|
| `--color-background` | `#FBECFF` |
| `--color-text` | `#1E1A20` |
| `--color-headline` | `#622690` |
| `--radius` | `8px` |

## 2. Tipografia

**Fonte:** Work Sans  
**Import:** Google Fonts — variável completa (100–900, itálico incluso)

```
https://fonts.googleapis.com/css2?family=Work+Sans:ital,wght@0,100..900;1,100..900&display=swap
```

| Uso | Tamanho | Peso | Line-height |
|---|---|---|---|
| H1 — Headline principal | 56px | 700 | 1 |
| H2 — Headline de seção | 36–40px | 700 | 1 |
| H3 — Subheadline / card | 20px | 600 | 1 |
| Texto corrido | 16–18px | 400 | 1.6–1.7 |
| Caption / apoio | 14–15px | 400 | — |

> ⚠️ Títulos não usam line-height além de 1.

## 3. Espaçamentos e Grid

| Token | Mobile | Desktop |
|---|---|---|
| Container max-width | — | `1440px` |
| Padding lateral das seções | `24px` | `80px` |
| Padding vertical das seções | `64px` | `120px` |
| Gap entre elementos | `24px` | `48px` |
| Gap entre cards (grid) | `24px` | `24px` |

## 4. Ondas

A ser definido verbalmente pelo usuário. As ondas funcionarão como divisores visuais entre seções.  
Arquivos serão colocados em `public/assets/waves/`.

## 5. Imagens

A ser definido pelo usuário.  
Arquivos serão colocados em `public/assets/images/`.
